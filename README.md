# 🏥 Dreamweaver--Hospitals

A responsive, modern single-page website designed for hospital management, patient information, and medical service showcase. This repository contains the complete source code, video demonstrations, and structural documentation of the project.

---

## 📁 Project Directory & Structure

The project components are organized into the following direct folders:

*   **`e-project-hospital/`** – The core workspace of the web application.
    *   `index.html` – The main portal/homepage of the hospital system.
    *   `style.css`, `service.css`, `vaccine.css` – Complete styling sheets for the user interface.
    *   `images/` – Graphical assets, icons, and gallery components used within the portal.
*   **`doc/`** – Contains the complete project report, database structure, and visual layout plans.
*   **`images/`** – High-resolution backup image assets for the project.
*   **`vedioas/`** – Contains the functional video demonstration clip showing the application in action.

---

## 📋 Project Documentation Index

The comprehensive documentation inside the `doc` folder includes:
1. **Project Synopsis & Analysis** – High-level overview of the hospital system, its scope, and core problem definitions.
2. **System Design & Visuals** – Visual diagrams mapping out the structure:
    * Data Flow Diagrams (DFDs)
    * Process Diagrams & System Flowcharts
    * UI/UX Screen Mockups & Screenshots
3. **User Guide** – A complete end-user manual explaining how a patient or staff member can navigate and utilize the system.
4. **Developer’s Guide** – Technical breakdown of modules, class linkages, and source code comments to allow any external developer to easily scale the code.

---

## 💻 Tech Stack Used
* **Frontend:** HTML5, CSS3 (Semantic Layouts)
* **Architecture:** Responsive Single Page Architecture (SPA Concept)
* **Hosting Platform:** GitHub Pages
